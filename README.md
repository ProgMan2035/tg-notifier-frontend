# Frontend
=======
TG Notifier
=============

Веб-приложение, на базе GREEN-API, созданное для получения уведомлений и отправки для этих уведомлений сообщения.
Для данного проекта подготовлен тестовый бэкенд на тот случай, если через GREEN-API не работает.

Интсрукция для локального запуска проекта
=============

1. Скопировать репозиторий.

```
git clone git@github.com:ProgMan2035/tg-notifier.git
```

2. Собрать и запустить.

```
npm run build
npm run preview
```

3. Заполнить форму с данными. Номер телефона указать того, с кем вы хотите создать чат.
4. Отправляете сообщение и ждёте, когда на него ответят. Или ждёте, когда придёт уведомление вам, потом отвечаете на него.
